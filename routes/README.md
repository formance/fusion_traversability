# 巡检采样路线

路线包括 28 个采样点，按巡检顺序编号为 01～28。`patrol_plan.png` 展示点位和车头朝向，同一坐标复访时箭头可能重合。`patrol_plan.json` 保存顺序、位置、朝向及相邻点的几何检查结果。

对每一相邻点，以前一点的 front_perception 为原点检查前向 1～8 m、左右 ±3 m，且下一点的地面位置落在理想相机与雷达视锥内；27 段均通过，静态线段到物体保守包围盒的最小距离为 1.00 m。视锥计算不能证明无遮挡、点云覆盖或区域可通行；直线净距未验证车辆转弯扫掠及动态障碍。路线尚未执行，应在仿真中用世界真值、安全停车和同步采集门限验证。
